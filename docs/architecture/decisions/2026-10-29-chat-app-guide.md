# 2026-10-29 — «Как работает приложение» в чате: карточка пути вместо несуществующей «Справки»

**Kind:** founder decision
**What:** 2026-10-28 основатель спросил агента в чате iOS «как работает приложение». Агент вызвал
`open_screen('help')`, написал, что «под ответом появилась кнопка со справкой», и настаивал трижды — а в
приложении у `menu:help` нет экрана (iOS `AgentReplyAction.target` его намеренно не рисует), и сервер всё
равно отвечал модели «кнопка выдана». Теперь:
- Агент вызывает `show_app_guide` (вид `read`, ничего не пишет): под ответом — полоса из пяти шагов
  (`match` подбор в HH:MM из `MATCH_CRON_SCHEDULE` → `blind` решение вслепую → `plan` билет, время и место →
  `date` встреча → `morning` утро после) с отметкой «ты здесь» на настоящем шаге человека. Шаг читается
  тем же путём, что холст (`deriveDateState` по текущему матчу или завершённому, ждущему отзыва) плюс
  неотвеченный утренний вопрос (`pendingMorningAfterFor`). Не прочитался — карточка без отметки.
- В чате приложения `open_screen` с `help`, `city`, `rematch` (экранов в приложении нет) не исполняется:
  модель получает `no_such_screen_in_app` и запрет говорить о кнопке; с карточкой — подсказку вызвать
  `show_app_guide`.
- Описание `help` в `open_screen` исправлено: это контакты поддержки, а не «как работает продукт» — для
  Telegram тоже (там «Справка» и есть одна строка про поддержку, `helpBody`).

Вид карточки (полоса, свои знаки шагов) выбран и одобрен основателем 2026-10-29 по снимкам; журнал iOS
2026-10-29.

**Why:** путь из пяти шагов прозой не объясняется; а инструмент, который отвечает «успех» на кнопку,
которую клиент не рисует, делает из модели лжеца.

**Как устроено (чтобы не переизобретать):**
- Только для сборок с `guide` в `X-Gennety-Chat-Cards`; без него инструмента и `GUIDE_ADDENDUM` нет.
  Telegram (`menu-agent.ts`) его не видит.
- Хранение — `messages.attachment` с `kind: "app_guide"` (колонка вишлиста и `offer`); наружу — полем
  `guide` в ответе хода, голосового хода и истории. Одна карточка на ответ: вишлист, `offer` или `guide`.
- В истории карточка отдаётся такой, какой была показана: шаг не перечитывается.
- Тексты шагов — ключи `guide*` в `packages/shared/src/i18n.ts` на пяти языках; знак шага выбирает
  приложение по `key`.

**What it changes going forward:** новый экран, на который агент может дать кнопку, сначала должен
появиться в приложении — иначе он попадает в `APP_SCREENLESS` (`chat-agent.ts`), а не в ответ модели
«кнопка выдана».

(`ChatAppGuide`); выкат — `docs/operations/deploy-journal/pending.md` (PENDING 2026-10-29).
